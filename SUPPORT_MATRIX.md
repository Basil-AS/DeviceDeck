# Device support matrix

Status meanings: **Not started** = no DeviceDeck implementation; **Researching** = source/app evidence being examined; **Protocol only** = reusable frame codec exists but there is no platform discovery/UI integration; **Transport only** = platform BLE/GATT discovery and link exist, but no model protocol session or user controls; **Implemented** = app code exists but hardware validation is incomplete; **Verified** = tested on the named OS, device revision, and firmware. “Cataloged” alone never means verified.

## Evidence required to mark a feature verified

- Exact marketed model, hardware revision, regional variant, and firmware.
- OS version, Bluetooth adapter/phone, and app build.
- Read trace before and after a change; command/response decoded with confidence noted.
- Reconnect and persistence behavior.
- Whether the official app/system service must release an exclusive control connection.

For inherited realme profiles, listed controls describe mappings in the existing Android/Windows code, not verified results from a DeviceDeck build. Other feature names are investigation targets, not claims that every model supports every item.

## Current static evidence

Baseus Intelligent 2.18.0 includes model-specific UI and command paths. EP10 Pro and Bowie MF1 select RFCOMM/SPP in the observed app flow; Bowie 30 and Blade 2 use BLE, with Blade 2 on a separate power-device flow. A live regional BLE dictionary now provides UUIDs for 149 models, including all four requested Baseus models. DeviceDeck's single Android/macOS/Windows/Linux apps now have EP10 Pro battery/noise support on Android/macOS, MF1 battery support on Android/macOS, Bowie 30 controls on all platforms, and Blade 2 power telemetry/display controls on Android. These paths still need physical-device validation. [`research/baseus-reference`](research/baseus-reference) is a protocol/source checkout, not an additional DeviceDeck application. It includes an EU catalog of 149 model/GATT profiles and a Blade 2-140 app-layer codec/parser. Blade 2 discovery/session/UI for Windows/macOS and Android/Windows EP10 Pro/MF1 remain open. See [`research/baseus-intelligent-findings.md`](research/baseus-intelligent-findings.md), [`research/baseus-ble-config-catalog.csv`](research/baseus-ble-config-catalog.csv) and [`research/baseus-reference/docs/protocol/blade-2-mobile-power.md`](research/baseus-reference/docs/protocol/blade-2-mobile-power.md). The current realme Link base APK decompilation has not yet yielded explicit Air 7/Air 7 Pro names; continue checking splits, native/assets data, and catalog services.
